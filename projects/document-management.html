Document Management Tools

A collection of Excel/VBA utilities that make documents easier to index, search, route, link, and retrieve without requiring a complex software platform.

The problem

Shared documents are hard to use when staff must remember folder locations, long filenames, or different routing rules. Broken absolute links also make workbooks difficult to move between approved locations.

Tools developed

  • Excel Document Manager with rapid search and direct file opening
  • Staff File Router for consistent document placement
  • Inspection Reminder for time-sensitive follow-up
  • Relative-link logic to improve portability
  • Clear controls designed around common user tasks

Design principle

I build from the workflow outward: first understanding what the user is trying to find or complete, then reducing the number of decisions and steps required.
